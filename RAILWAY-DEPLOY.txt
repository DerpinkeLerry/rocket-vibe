ROCKET VIBE 0.9 - RAILWAY / 4 PLAYER

Das Projekt ist fuer einen einzelnen Railway-Service vorbereitet.

Railway:
- Build Command: npm run build
- Start Command: npm start
- Healthcheck: /health
- Server lauscht auf 0.0.0.0 und process.env.PORT
- WebSocket laeuft auf derselben Domain unter /lan
- 1 Replica verwenden

Deployment nach GitHub-Aenderungen:
  git add .
  git commit -m "4 player authoritative multiplayer"
  git push

Danach deployt Railway automatisch.

Alle Spieler oeffnen exakt dieselbe Railway-URL.
Die ersten vier Verbindungen erhalten Spieler 1, 2, 3 und 4.
Ein fuenfter Spieler bekommt "Match voll".

WICHTIG:
Ab 0.9 ist kein Browser mehr der Physik-Host.
Railway simuliert zentral alle vier Autos und den Ball. Dadurch funktioniert die Steuerung fuer jeden Spieler ueber denselben Input-Pfad.

DEBUG: https://DEINE-DOMAIN/debug/game zeigt den Live-Serverzustand.
