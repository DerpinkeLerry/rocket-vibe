ROCKET VIBE 1.4 - GO + RAILWAY

1. Projekt in ein GitHub-Repository pushen.
2. Railway: New Project -> Deploy from GitHub repo.
3. Falls Monorepo: diesen Ordner als Root Directory waehlen.
4. Deploy starten. Railway verwendet automatisch das Dockerfile.
5. Networking -> Generate Domain.
6. Dieselbe Domain an alle 1-4 Spieler geben.

Keine Pflichtvariablen. Railway setzt PORT automatisch.

Health:    /health
Config:    /config
Diagnose:  /debug/game
WebSocket: /lan

WICHTIG:
- Genau 1 Replica verwenden; der Matchzustand liegt im Speicher des Go-Prozesses.
- Region ist in railway.json auf Amsterdam gesetzt.
- Serverphysik 120 Hz, binaere Snapshots 60 Hz.
- Frontend und Go-WebSocket laufen auf derselben Domain.
- Ein Redeploy trennt eine gerade laufende Runde.
