ROCKET VIBE 0.9 - 4 SPIELER LAN

1. npm install
2. npm run lan
3. Host oeffnet http://localhost:5173
4. Freunde oeffnen die im Terminal angezeigte LAN-IP.

Bis zu vier Geraete koennen gleichzeitig verbinden.
Alle Spieler verwenden WASD / Space / Shift / Q / E.
Die gesamte Match-Physik laeuft zentral im Node-Server, nicht im Browser von Spieler 1.
