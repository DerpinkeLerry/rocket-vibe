ROCKET VIBE 1.12.0 - BIS ZU 8 SPIELER LAN / GO SERVER

Windows:
- start-windows.bat doppelklicken

macOS / Linux:
- ./start-mac-linux.sh

Manuell:
1. npm ci
2. npm run lan
3. Im Browser http://localhost:8080 oeffnen
4. Freunde im selben Netzwerk verwenden http://DEINE-LAN-IP:8080

Im Lobby-Browser erstellt ihr eine Lobby und stellt die Kapazitaet per Slider auf 1 bis 8 Spieler.
Der Standard bleibt 4 Spieler. Die Slots wechseln automatisch zwischen Orange und Blau.

F2 schaltet Normal / Ultra High / Ultra Low.
